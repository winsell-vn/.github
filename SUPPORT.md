# Support

## Where to ask

| You want to… | Go to |
| --- | --- |
| Report a bug | Open an issue in the affected repository |
| Request a feature | Open a feature request issue in the affected repository |
| Ask how to use a product | [contact@winsell.vn](mailto:contact@winsell.vn) |
| Report a security vulnerability | [Private advisory](https://github.com/winsell-vn/.github/security/advisories/new) — **not** a public issue |
| Discuss conduct | [conduct@winsell.vn](mailto:conduct@winsell.vn) |
| Commercial or partnership inquiry | [contact@winsell.vn](mailto:contact@winsell.vn) |

## Before you open an issue

1. Search the repository's closed issues — the answer is often already there.
2. Check the repository README and any `docs/` folder.
3. For setup problems, include the exact command you ran and its full output.

## A good bug report contains

- repository and version (or commit SHA)
- environment: OS, Node.js version, database and Redis versions
- exact steps to reproduce
- what you expected vs. what happened
- full error output, with secrets redacted

## Response times

This is a free and open-source project maintained alongside commercial work.
There is no guaranteed response time, but issues are usually triaged within a
few business days. If you need a hard SLA, that is a commercial engagement —
email [contact@winsell.vn](mailto:contact@winsell.vn).
